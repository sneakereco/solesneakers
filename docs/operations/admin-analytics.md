## Refresh finite observations

One invocation leases one partition for up to 30 seconds. Repeat to drain splits. Each leaf compares both directions for all finance fields, revisions, update timestamps, link contents and tombstones. The two source reads bracket the provider reads; the source can be idle. Overflow splits a hash prefix into all sixteen children, covering facts at identical effective times. Successful leaves persist observer-only progress. A completed sweep records the minimum actual source observation among matched leaves. A changing multirow leaf can refine up to eight hash characters during a sweep. Later runs recheck late and backdated commits. This is a set of finite leaf observations. The connector supplies no cross-Endpoint snapshot. An incomplete sweep, expired lease, malformed value, missed update, quota limit or unavailable comparison cannot advance the proof.

For native-only history, use a protected owner attestation file containing `environment`, `projectId` (string), `region` (the API origin), `activationInstant`, `geoIpDisabled` and `sourceAndDefinitionsVerified`. The database immediately suppresses a known downgrade below 24 months. The last successful observation expires after 24 hours if the metadata service becomes inaccessible. A later retention increase cannot restore an already expired period. The native activation command enforces a confirmed marker before or at the launch and within ten minutes. An existing late-start dataset keeps its explicit initial gap. Use `--history archive` only for the separately qualified archive configuration. The database excludes native evidence after the 24-hour attestation expires and clips continuously to the later of the observed provider retained-from date and its effective rolling horizon.

The observer generates opaque marker UUIDs at server time, excludes them from all visitor reports, and reads back adjacent markers with the fixed native Endpoint.
